# C10: Test explorer

**Scope:** `ide-test`. The component must be implemented, not just compile. See `ARCHITECTURE.md` and `tests/TEST_MATRIX.md`.

## Public interface concepts

TestAdapter, TestNode, TestRun, TestResult. Concrete Rust API design is owned by the architecture agent and must remain versioned and acyclic. Use explicit immutable IDs, typed error surfaces, bounded async notifications and capability negotiation where appropriate.

## Acceptance and fixtures

Cargo/pytest/Swift/JUnit/Bun adapter fixture, debug a test, rerun failures. Record command, target runtime, exit status, negative cases and evidence file hashes. Include regression cases, not just success path. Benchmark where on critical path.

## Threat/failure scenarios

Misparsed test results, unfinished runner, false green. These are mandatory negative tests. Fault injection must never corrupt the authoritative document, change host security settings, or leak credentials.

## Ownership and dependency

The relevant graph task in `engineering/graph/seed.json` owns this contract. When an interface changes, mark dependent tests, proofs and implementations dirty. Accepted laws cannot be weakened. Unit tests do not replace actual interactive TUI verification.
