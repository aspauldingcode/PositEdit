# Privacy, trust and budgets

Zero external telemetry and no cloud dependency. Workspace indexing stays local. External commands respect existing workspace trust. Process probes need explicit permission and avoid reading protected memory. Never embed secrets in workspace snapshots, logs, or trace exports. Scrub ANSI control sequences from untrusted logs; never execute them. Validate paths against workspace authorization. Sandbox SVG/PDF renderers when supported. Per-service cancellation, CPU/memory/disk budgets, bounded queues, quotas and timeouts. Targets (not measured): no regression in editor input latency; idle DLC4 services near-zero CPU; no graphics backend loaded when unused; overview opens within one host animation frame once data cached; 1000+ output events handled with backpressure; trace retention configurable internally by sensible default. Measure on actual M1 and NixOS hosts, report p50/p95, memory and cold-start.
