# Renderer, animation and graphics contract

Host owns all terminal writes. New views contribute `RenderFragment` or host-native widget instructions. Pixel surfaces managed by a single `GraphicsArbiter`: surface ID, owner pane, revision, rectangle, z-order, backend, damage, lifetime and cleanup. Clip to pane bounds. On focus/resize/scroll update or delete images before redrawing; never leak escape sequences into log streams. Detect terminal protocol support safely, use bounded probes and cache result. Kitty, Sixel and iTerm2 are optional, not universal. Non-support -> Unicode/text fallback. Animation timing remains host-defined, respect reduced-motion accessibility and terminal throughput. Track p50/p95 frame latency and dropped frames. Avoid rasterization on input thread. GPU preview should not initialize until visible.
