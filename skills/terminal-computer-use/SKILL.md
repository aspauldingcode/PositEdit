# Real TUI evaluation without GUI assumptions

Use tmux detached panes, capture-pane, send-keys, resize-window, script recordings, PTY/expect; test Unicode, keyboard navigation, mouse optional, terminal restoration, errors and split layouts. Only use macOS screen capture after OS permission exists. Do not treat generated screenshots as evidence.

**Procedure:** inspect actual environment -> identify contracts and acceptance tests -> execute minimal change -> capture concrete proof/build/test evidence -> update graph -> stop or continue only if permitted by policy. Read `AGENTS.md`, `ARCHITECTURE.md` and `engineering/VERIFICATION.md`. See `REFERENCES.md` for official sources.
